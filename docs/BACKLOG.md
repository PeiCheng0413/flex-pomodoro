# Backlog

## 已定案

### 2026-10 習慣追蹤（v0.3.0）

- 模板改為習慣，計時一定要選習慣，或選「單純計時」。單純計時的紀錄進「未歸類」，可事後歸入習慣。
- 習慣有每日目標分鐘數與每週目標天數；當天工作時間達到每日目標＝當天達成，一週達成天數達到目標＝當週達標。不看每週總時數。
- 目標變更不改寫過去（`habit_goals` 變更紀錄），編輯時可選「也套用到過去」。
- 習慣只能封存，不能刪除；可合併。
- 從模板版升級時，舊的空白名稱紀錄進未歸類，不另建「未命名」習慣。
- 導覽：習慣／計時／設定。統計併入習慣頁（總覽熱圖＋卡片＋詳細頁），拿掉原本的本週／本月／全部切換，改在詳細頁顯示三個期間的總時數。
- 熱圖採 GitHub 式（一欄一週、星期一在上），四階顏色，欄下方綠條表示當週達標。
- 一天從午夜開始；跨午夜的專注依時間切開。
- 顯示連續達標週數（以週計算）。
